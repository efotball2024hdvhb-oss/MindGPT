# 🧠 MindGPT - دستیار هوشمند اندروید

اپلیکیشن چت‌بات مدرن اندروید با رابط کاربری الهام‌گرفته از ChatGPT، ساخته شده با **Jetpack Compose**، پایگاه‌داده **Room** و معماری **MVVM**.

---

## ✨ امکانات کلیدی

- **ویرایش پیام‌ها با لمس طولانی (Long-press to Edit):** لمس طولانی روی پیام‌های ارسالی یا لمس آیکون مداد برای ویرایش پیام و بازتولید خودکار پاسخ.
- **تم تیره مینیمال و زیبا (ChatGPT Dark Mode):** سازگار با استانداردهای طراحی مدرن و رنگ‌بندی تیره ملایم.
- **منوی تاریخچه گفتگوها (Sidebar Drawer):** ایجاد چت جدید، جستجو در بین گفتگوها و مدیریت تاریخچه‌ها.
- **انتخاب مدل هوش مصنوعی:** جابجایی بین مدل‌های مختلف (MindGPT 4o، MindGPT Pro و Flash Lite).
- **حالت تفکر عمیق (Deep Thinking):** استدلال گام‌به‌گام برای مسائل محاسباتی، علمی و کدنویسی.
- **جستجوی زنده وب (Live Web Search):** دریافت داده‌های به‌روز.
- **مکالمه صوتی زنده (Live Voice Mode):** تجربه گفتگوی صوتی با جلوه بصری امواج درخشان.
- **ذخیره‌سازی پایدار و آفلاین:** ذخیره تمام مکالمات در حافظه دستگاه با Room Database.

---

## 🚀 نحوه اجرا

### روش اول: دانلود مستقیم APK از گیت‌هاب (GitHub Actions)
1. وارد تب **Actions** در بالای ریپازیتوری گیت‌هاب شوید.
2. روی آخرین بیلد تحت عنوان **Build MindGPT Android APK** کلیک کنید.
3. در پایین صفحه بخش **Artifacts**، فایل **MindGPT-app-debug** را دانلود و روی گوشی اندرویدی خود نصب کنید.

### روش دوم: اجرا در Android Studio
1. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/USERNAME/REPO_NAME.git
   ```
2. پروژه را در **Android Studio** باز کنید.
3. فایل `.env.example` را به `.env` کپی کرده و در صورت تمایل کلید API را وارد کنید:
   ```
   GEMINI_API_KEY=your_key_here
   ```
4. دکمه **Run (▶)** را برای اجرا روی شبیه‌ساز یا گوشی واقعی بزنید.

### روش سوم: ساخت فایل نصبی با خط فرمان (CLI)
- در ویندوز:
  ```cmd
  gradlew.bat assembleDebug
  ```
- در لینوکس / مک:
  ```bash
  ./gradlew assembleDebug
  ```
فایل نصبی در مسیر زیر ساخته می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`
