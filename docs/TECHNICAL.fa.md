# MindGPT · مایند جی‌پی‌تی

وب‌اپ مستقل، فارسی و انگلیسی، با ظاهر تیره بر اساس ۳۵ تصویر مرجع ارائه‌شده. مناسب عرض موبایل، تبلت و دسکتاپ، با فونت محلی **Vazir** و امکان نصب به شکل PWA روی اندروید. این پروژه محصول رسمی OpenAI یا اشتراک رسمی ChatGPT نیست.

## امکانات

- گفتگو با پاسخ تدریجی و امکان توقف، Markdown، کد قابل کپی و فرمول ریاضی.
- دریافت فهرست زنده مدل‌ها از `GET /v1/models` و انتخاب مدل در تنظیمات؛ مدل‌های embedding در فهرست دیده می‌شوند اما برای گفتگو انتخاب نمی‌شوند.
- نگه‌داشتن پیام، کپی، انتخاب متن، ویرایش و ارسال دوباره؛ منوی پاسخ با Retry، جست‌وجوی وب، شاخه جدید، بازخورد و پخش صدا.
- کشوی گفتگوها، جست‌وجو، پین، تغییر نام، حذف با تأیید، آرشیو، گروه‌بندی پروژه و خروجی JSON.
- آپلود تصویر، دوربین، فایل متنی، PDF متنی و DOCX؛ کتابخانه فایل و نمایش تصویر. سقف هر فایل ۱۰ مگابایت، ۴ فایل در هر پیام و ۸ مگابایت تصویر در زمینه درخواست است. استخراج PDF تا ۸۰ صفحه / ۸۰هزار نویسه انجام می‌شود.
- ضبط گفتار با درخواست مجوز میکروفون، موج صدا، مکث/لغو و تبدیل به پیش‌نویس با تأیید کاربر؛ متن بدون فشردن دکمه ارسال فرستاده نمی‌شود.
- پخش متن پاسخ با صدای نصب‌شده مرورگر/گوشی، نوار پخش، مکث و سرعت قابل تنظیم.
- تنظیمات فارسی/انگلیسی، تیره/روشن/سیستم، بازخورد لمسی و دستور سفارشی.
- صفحه Get Plus با توضیحات رسمیِ منبع‌دار و لینک تماس `https://t.me/dev_vexel`؛ تماس با فروشنده به معنی فعال‌شدن اشتراک یا پرداخت داخل برنامه نیست.
- یادآورهای قابل ذخیره با خروجی تقویم ICS؛ اجرای خودکار گفتگو در پس‌زمینه ندارد.

## اجرای محلی

نیازمندی: Node.js 22.13 یا جدیدتر و pnpm 11.25.0. پروژه با Vinext / React 19 روی Cloudflare Workers اجرا می‌شود. D1 برای گفتگوها و R2 برای فایل‌هاست؛ یک میزبان صرفاً استاتیک کافی نیست.

```sh
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
```

در `.env` مقدار `CODECRAFT_API_KEY` را قرار بده. `CODECRAFT_BASE_URL` پیش‌فرض `https://codecraftapi.com/v1` است. کلید در مرورگر، فایل ZIP و مخزن قرار نمی‌گیرد. کلید ارائه‌شده برای نسخه میزبانی‌شده در تنظیمات محرمانه سرور ثبت شده است.

برای اولین اجرای مستقل، ابتدا خروجی سازگار با Worker و پایگاه داده محلی را بساز:

```sh
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_violet_blade.sql
pnpm dev
```

Migration اولیه را روی یک پایگاه داده فقط یک بار اجرا کن. فرمان `pnpm dev` نشانی محلی را چاپ می‌کند. در محیط مدیریت‌شده Sites، پیش‌نمایش با `sites-preview start` اجرا می‌شود. با تغییر schema، یک migration جدید بساز؛ فایل اعمال‌شده قبلی را تغییر نده.

```sh
pnpm typecheck
pnpm build
pnpm start
```

نسخه ZIP شامل منبع و قفل وابستگی‌هاست؛ `node_modules`، داده‌های شخصی، فایل‌های آپلودشده، خروجی build و کلید محرمانه در آن نیست. روی میزبان جدید باید D1 با binding نام `DB`، یک R2 با binding نام `BUCKET`، migration و متغیرهای سرور تنظیم شوند. `.openai/hosting.json` شناسه نسخه Sites همین پروژه را دارد؛ برای ساخت سایت مستقل از حساب دیگر باید سایت و منابع جدید ثبت شوند.

## رفتار و محدودیت‌های واقعی

- ثبت‌نام داخلی وجود ندارد. نشست ناشناس در کوکی HttpOnly نگهداری می‌شود؛ گفتگوها بین دستگاه‌ها همگام نمی‌شوند و پاک‌کردن کوکی دسترسی به نشست قبلی را از بین می‌برد. لینک پیش‌نمایش خصوصی ممکن است کنترل دسترسی میزبان را داشته باشد.
- API از سرور فراخوانی می‌شود. تمام مدل‌های سرویس نمایش داده می‌شوند؛ امکانات هر مدل فقط طبق `capabilities` آن فعال می‌شوند. جست‌وجوی وب به مدل دارای `web_search` وابسته است. reasoning یک درخواست برای پاسخ دقیق‌تر است، نه نمایش افکار پنهان مدل یا اجرای ابزارهای دلخواه.
- CodeCraft در آزمون اتصال از محیط ساخت پاسخ **403** داد؛ پاسخ واقعی مدل با این کلید هنوز تأیید نشده است. تست‌های گفتگو با سرویس آزمایشیِ صریحاً برچسب‌خورده انجام شدند و در نسخه نهایی فعال نیستند.
- تولید و ویرایش تصویر، ویدئو، صدای مولد، اجرای کد، Deep Research و ابزارهای اختصاصی ChatGPT پیاده‌سازی نشده‌اند؛ مستندات بررسی‌شده CodeCraft برای آن‌ها قرارداد قابل اتکا ارائه نکردند. کتابخانه تصویر و تحلیل تصویر در مدل دارای Vision موجود است. مدل نمی‌تواند صرفاً با داشتن API گفتگو این قابلیت‌ها را فراهم کند.
- ورودی صوتی از Web Speech API مرورگر استفاده می‌کند؛ پردازش تشخیص گفتار ممکن است از سرویس مرورگر عبور کند. HTTPS، مجوز میکروفون و مرورگر سازگار لازم است. پخش فارسی به وجود صدای فارسی روی دستگاه بستگی دارد. روی دستگاه واقعی اندروید آزمایش نشده است.
- PWA جای APK بومی را نمی‌گیرد و برای ارسال پیام نیاز به اینترنت دارد. فقط دارایی‌های عمومی مثل فونت cache می‌شوند، نه API و گفتگوها.
- ظاهر از تصاویر مرجع الهام گرفته و جزئیات اصلی بازسازی شده‌اند؛ یکسان‌بودن پیکسلی روی تمام گوشی‌ها و دسترسی به سیستم داخلی ChatGPT ادعا نمی‌شود.

## ساختار منبع

| مسیر                         | کاربرد                                     |
| ---------------------------- | ------------------------------------------ |
| `app/page.tsx`               | رابط گفتگو، منوها و پنجره‌ها               |
| `app/globals.css`            | ظاهر موبایل، RTL، تم‌ها و انیمیشن‌ها       |
| `app/api/[...path]/route.ts` | API برنامه، نشست، گفتگو، فایل و پروکسی مدل |
| `lib/server.ts`              | اتصال محرمانه به CodeCraft و کنترل نشست    |
| `hooks/use-voice.ts`         | ضبط گفتار و پخش پاسخ                       |
| `lib/attachments.ts`         | استخراج متن فایل‌ها                        |
| `db/schema.ts`, `drizzle/`   | طرح و migration پایگاه داده                |
| `public/fonts/`              | فونت Vazir و مجوز OFL                      |
| `docs/QA.md`                 | دامنه آزمون‌ها و موارد تأییدنشده           |

وابستگی‌های متن‌باز مجوزهای خود را دارند. مجوز فونت در `public/fonts/OFL.txt` آمده است.
